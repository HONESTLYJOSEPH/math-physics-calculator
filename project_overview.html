C · Compiled
math_physics_calc.c
Fast, zero-dependency CLI tool. Pure C11 with the standard math library only. Runs anywhere — Linux, macOS, Windows (MinGW/MSVC).
# Compile gcc -Wall -O2 -o calc math_physics_calc.c -lm # — or — make
# Run ./calc
Python · Scripted
math_physics_toolkit.py
Interactive CLI with numpy / scipy / matplotlib integration. Automatically plots trajectories, histograms, regression lines & ODE solutions.
# Install deps pip install -r requirements.txt
# Run python math_physics_toolkit.py
